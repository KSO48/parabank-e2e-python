# ParaBank E2E — Python (портфолио)

Python-порт [TypeScript-версии](https://github.com/KSO48/parabank-e2e) этого
же проекта — те же два сценария, тот же набор реальных находок по сайту,
но на `pytest` + `pytest-playwright` вместо `@playwright/test`. Сделано,
чтобы показать один и тот же подход к автоматизации на двух языках.

Тесты для [ParaBank](https://parabank.parasoft.com) — публичного демо-банка
от Parasoft, официально созданного для практики автоматизированного
тестирования.

## Стек
- Python 3.11+
- `pytest` + `pytest-playwright`
- Обычный headless Chromium

## Что покрыто

- **`tests/test_customer_journey.py`** — полный путь клиента: регистрация →
  чтение номера автоматически созданного счёта → открытие второго счёта →
  перевод средств между своими счетами → повторный логин.
- **`tests/test_loan_request.py`** — заявка на кредит с двумя исходами
  (Approved/Denied) в зависимости от соотношения суммы взноса и доступного
  баланса — ближайший на этом сайте аналог сценария "заявление → решение".

## Особенности сайта (те же, что и в TS-версии — не переоткрывал заново, порт один в один)

1. **Нечёткая проверка уникальности username** — любой логин с префиксом
   вроде `qa_`/`test_`/`e2e_` стабильно получает "This username already
   exists.", даже если гарантированно уникален. Решение — `helpers/test_data.py`,
   генерация без узнаваемого префикса.
2. **CSS-локатор `#customer.firstName` — ловушка.** Точка после `#`
   означает класс, а не часть id. Нужен атрибутный селектор
   `[id="customer.firstName"]`.
3. **`base_url` с путём + `page.goto("/x.htm")` = потерянный путь.**
   Ведущий слэш в относительном пути сбрасывает путь из `base_url` до
   корня домена (WHATWG URL rules) — поэтому в `pytest.ini` `base_url`
   заканчивается слэшем, а во всех `page.goto()` пути без ведущего слэша.
4. **Открытие счёта — реальная гонка на стороне сайта.** Список счетов
   для перевода стартового депозита (`#fromAccountId`) заполняется
   отдельным AJAX-запросом уже после рендера страницы; клик раньше, чем
   список подгрузился, тихо ничего не делает. Тест явно ждёт заполнения
   списка перед кликом (`helpers/parabank_flow.py`, `open_new_account`).
5. **AJAX-результаты не меняют URL.** И "Open New Account", и "Apply Now" —
   `<button type="button">`, подменяющие контент через AJAX без навигации.
   Проверка результата — через ожидание текста, не `wait_for_url`.

Подробный разбор каждой находки — в TS-версии проекта, там же они были
обнаружены впервые через прямой дамп DOM/сети/JS-кода сайта.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
python -m playwright install chromium

pytest -v
```

Полезные флаги:
```bash
pytest --headed              # видно браузер вживую
pytest -v -s                 # подробный вывод
pytest tests/test_loan_request.py::test_loan_approved_when_down_payment_within_balance  # один тест
```

Каждый прогон создаёт своего уникального пользователя — сайт публичный и
общий для всех, кто его тестирует, поэтому изоляция теста держится на
уникальности сгенерированных данных, а не на выделенном окружении.
